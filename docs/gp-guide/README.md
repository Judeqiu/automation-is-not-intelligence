## 📝 使用建议

1. **新生：** 从 `01-gp-fundamentals.md` 开始 → 阅读 `03-knowledge-bank-building.md` → 开始搭建自己的 Bank
2. **JC1 在读：** 跟随 `02-study-methodology.md` 的每周训练计划 → 参照 `04-sample-knowledge-bank.md` 建 Bank
3. **JC2 备考：** 重点看 `02-study-methodology.md` 的 Phase 3（精准期）和错误追踪部分 → 使用 Sample Bank 作为质量参考
4. **家长/老师：** 阅读全套以理解 GP 的系统性学习方法，帮助指导学生学习
